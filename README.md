
# 🌿 Greenden - Plant Shop Website

Greenden is a simple **responsive plant shop website** built using **HTML, Tailwind CSS, and JavaScript**.
This project demonstrates basic frontend development concepts such as responsive layout, navigation menu, and product search functionality.

---

## 🚀 Features

* 🔍 **Product Search** – Users can search for plants using a JavaScript search feature.
* 📱 **Responsive Design** – Works on mobile, tablet, and desktop devices.
* 📋 **Navigation Menu** – Mobile-friendly menu for easy navigation.
* 🌱 **Product Display** – Shows plant products in a clean grid layout.
* 🎨 **Modern UI** – Styled using Tailwind CSS.

---

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
--




## 🔍 JavaScript Search Function

The website includes a search feature that allows users to filter products dynamically while typing.

Example concept:

* User types in the search box
* JavaScript checks product names
* Matching products are displayed
* Non-matching products are hidden
